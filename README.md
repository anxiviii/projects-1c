
## Содержимое

- примеры интеграции с внешними сервисами.
- учебные и экспериментальные проекты.

## Проекты

**загрузка курсов ЦБ РФ:** получение курсов через HTTP и XML (HTTPСоединение, HTTPЗапрос, ЧтениеXML, клиент-сервер).

**1C: ERP: автозаполнение «Отпустил»** – при создании документа «Реализация товаров и услуг» реквизит автоматически заполняется ответственным сотрудником склада из первой строки табличной части «Товары».

**интеграция с api погодой** - при вводе города в поле ввода, внизу мы получаем детальную информацию о погоде.

**учет продаж товаров с возвратами и скидками** - магазину нужно вести учет продаж товаров с возможностью возврата и применения скидок. необходимо создать документ для регистрации продаж, включающий учет возвратов и скидок, а также отчет для отображения проданных товаров за день.
